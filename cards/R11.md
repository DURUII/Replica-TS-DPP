# R11 — Eq (38): the assembly across rounds and episodes

**Status: CLOSED.**  `lean4/TSDPP/Regret.lean`

## Statement

```
episodeRegret_le {L} {K} (regret : ℝ) (diff delta : ℕ → ℝ)
    (hregret : regret = ∑ t ∈ range L, diff t) (h : ∀ t, |diff t| ≤ K·delta t) :
  |regret| ≤ K · ∑ t ∈ range L, delta t

regret_le {m L} {K} (episodeRegret : ℕ → ℝ) (delta : ℕ → ℕ → ℝ)
    (h : ∀ l, |episodeRegret l| ≤ K · ∑ t ∈ range L, delta l t) :
  |∑ l ∈ range m, episodeRegret l| ≤ K · ∑ l ∈ range m, ∑ t ∈ range L, delta l t
```

## Consumes

**`L34` = Lemma 3 + Lemma 4 of the paper, quoted from [28]** — *as a hypothesis, not an axiom*.
Both statements take the per-round Bellman bound and the decomposition as premises.  R10 supplies
the per-round bounds `K = ½C² + (2C²+2CD+C)L` that instantiate them.

## Consumed by

R16.

## Proof route

`abs_sum_le_sum_abs` then `sum_le_sum` then `mul_sum`.  Note that **`K ≥ 0` and `δ_t ≥ 0` are not
needed**: the triangle-inequality route never uses them (trap P-14).  Both hypotheses were present
in the first draft, the linter flagged them unused, and the statements were sharpened rather than
the linter silenced.  `K`'s nonnegativity is needed *downstream*, where it is multiplied — recorded
as `regretCoeff_nonneg` in `TSDPP/Rate.lean`.
