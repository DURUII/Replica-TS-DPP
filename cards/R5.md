# R5 — the exact law of `X_i(t)` given the record (paper Eq (15))

**Status: CLOSED.**  `lean4/TSDPP/Belief.lean`

## Statement

`pmf θ lam δ x = if x < δ then θ * (1 - θ) ^ x else if x = lam + δ then (1 - θ) ^ δ else 0`
`pmf_sum_one (θ : ℝ) (lam δ : ℕ) : ∑ x ∈ range (lam + δ + 1), pmf θ lam δ x = 1`

## Consumes

Nothing.

## Consumed by

R6, R9, R10.

## Proof route

`Finset.sum_subset` onto `range δ` (the entries with `δ ≤ x < λ+δ` vanish), the geometric sum
`θ · Σ_{x<δ}(1−θ)^x = 1 − (1−θ)^δ` — which is `geom_sum_mul_neg` and needs **no division** — then
`ring`.

## Notes

The division-free route is what keeps `pmf_sum_one` free of a `θ ≠ 0` side condition (trap P-2).
`Belief.theta_mul_geom_sum` is stated for **every** real `θ`, including `0`.
