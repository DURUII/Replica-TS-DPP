## 概述

```
@inproceedings{zhou2026age,
  title={Age-of-Information-Aware Mobile Crowdsensing for Uncertain Event Capture},
  author={Zhou, Jinrui and Xu, Yin and Xu, Haotian and Xiao, Mingjun and Wu, Jie},
  booktitle={IEEE INFOCOM 2026 - IEEE Conference on Computer Communications},
  pages={1--10},
  year={2026},
  organization={IEEE},
  doi={10.1109/INFOCOM59046.2026.11571737}
}
```

论文把不确定事件捕获建模为一个受限 episodic restless bandit，其转移概率未知，并提出 **TS-DPP**：
把 belief-Drift-Plus-Penalty bandit 策略与 Thompson sampling 结合起来。它的头号理论主张是
**Theorem 2**（§IV, Eq (19)）：

> 贝叶斯遗憾满足 `BR(T) = O( √(L³ · T · log T) )`，
> 其中 `T = m·L` 是时域，`L` 是每个 episode 的长度。

`CLAUDE.md` 要求交付两件彼此独立的成果物——一份非形式化的证明或反证，以及它对应的 Lean 4
形式化——并且在两者都通过独立验证之前不允许宣布成功。本仓库就是这一对，外加每一条没能走通的
路线的记录。论文实验的复现是第三件彼此独立的成果物，放在
[code/README.md](code/README.md)。

`theorem2_rate` 给出

```
|BR| ≤ 8·(C²/2 + 2C² + 2CD + C) · L · √(L³ · T · log T / η)
```

其中 `T = m·L`。因此论文速率里的全部数值内容都是机器校验过的，而那个 `L` 被保留在明处，没有被
悄悄吸收进常数。

## 如何检查

一条命令完成全部验证：

```
cd lean4
./scripts/check_axioms.sh
```

它会构建根模块，对 `TSDPP/Audit.lean` 做 elaborate，并拒绝任何 elaborate 阶段的报错；按名字逐条
核对每一条 `#print axioms`，拒绝任何依赖三种许可公理之外公理的声明，扫描每个源文件在注释之外的
`sorry`/`admit`/`native_decide`/`unsafe`/`axiom`/`opaque`，并要求 `TSDPP/` 下每个模块都可从根模块
到达。同样的各步分开跑如下，外加上门禁不跑的那个数值证伪脚本：

```
export PATH="$HOME/.elan/bin:$PATH"
lake build                                    # the whole development
lake env lean TSDPP/Audit.lean                # the raw #print axioms report
python scripts/scan_forbidden.py              # the comment-aware source scan
python ../scripts/numeric_check.py            # the numeric falsifier, independent of the gate
```

全绿意味着没有 `sorry`、没有新公理、没有 `native_decide`、没有 `unsafe`，且每一条被审计的声明
都有干净的 `#print axioms`。它**不**意味着这些陈述就是论文所陈述的那些：那是另一项审计，见
[FIDELITY.md](FIDELITY.md)，其结论概述在下面「成果物的边界」一节。`Float` 是 `CLAUDE.md` 那张
单子上唯一没有门禁覆盖的项：`scan_forbidden.py` 有意不扫它，所以这一项靠人看，而不是靠脚本。

## 论文走不通的地方

以下是成果物无法跟随论文的地方。每一条都陈述论文的那一步、成果物代之以确立了
什么，以及该结论的适用范围。完整记录见 [DESIGN.md](DESIGN.md) §5 与 §7。

### 1. Lemma 5 是为 `0 ≤ r ≤ 1` 陈述的，却在 `r ≥ 1` 上被使用

论文把 Beta 集中不等式（p. 9, Eq (31)）陈述在 `0 ≤ r ≤ 1` 上，而 Eq (33) 随后把它用在
`r = max{1, √(8 log T/α)}`，也就是 `≥ 1`。成果物继承了这次越界使用，把带常数 `c₀ = 11/100` 的
`r ≥ 1` 形式注册为目标，随后**在 Lean 内部反证了自己的注册目标**：`∀` 陈述只需一个反例，而
`(α, β, r) = (1, 100, 14)` 这个反例的整条证明链只是一次多项式积分。证书是初等的包含关系
`{X ≥ t} × {Y ≤ u} ⊆ {|X − Y| ≥ s}`（只要 `s ≤ t − u`），用在 `t = 15/101`、`u = 1/101` 处，此时
`t − u = 14/101 = s` 恰好取等，于是下界就是两个 `Beta(1, B)` 单样本尾概率之积
`LB = (86/101)^100·(1 − (100/101)^100)`。相对注册界 `2e^{−539/25}`，`LB / RHS = 75.79`。

第二条头号定理用同一份证书反证了**论文自己的常数 `1/8`** 在同一范围上的形式。两条都是无条件
的，且都经过审计。

**要紧的是适用范围。** 论文自己的 Lemma 5（在 `0 ≤ r ≤ 1` 上）**没有被反证**——反例落在
`r = 14`，完全在该范围之外，而且那个范围根本不可能被越出：当 `r → 0⁺` 时两侧之比从下方趋于
`1/2`。论文的定理同样没有被反证。一步证明走不通不等于定理为假，而要反证该定理需要一个遗憾的
反例，那又需要本成果物从未形式化的问题陈述。这里确立的是：论文在 `r ≥ 1` 上使用的那个界**为假**，
且已由机器无条件校验；它对论文的后果是一次**引用失败**，即 Eq (33) 把 Lemma 5 用在了它被陈述
的范围之外。`cards/L5-REFUTATION.md` §0 载有这段适用范围说明，在引用 `75.79`
这个数字之前应当先读那一节。

一个错到这个地步的常数居然能保留到投稿，原因是结构性的，也正是这处发现值得占这些篇幅的原因：真实
的双样本尾指数约为 `αr²/2`，而论文声称的是 `αr²/8`。在 `r ≤ 1` 上，声称的指数远*大于*真值，
于是界被舒服地满足，看上去毫无问题；缺口只在 `r` 变大时才张开。一个弱了四倍的常数，恰好在论文
检验它的那个区域内是隐形的。

### 2. 没有任何一个范围能修复这次使用

「把它重新陈述在论文印出来的那个范围上」听上去像是个走流程的修补，其实不是；在投入一次修补
之前，把这一点确定下来是值得的。三条路线都试过，各自死于不同的原因。并集拆分需要
`t₁ − t₂ = μ(1+δ₁−δ) ≤ rμ`，即 `r ≥ 1`，所以方法的范围与陈述的范围内部不相交：当 `r ≤ 1` 时，
小下尾的取法 `δ → 0` 迫使 `δ₁ ≤ r − 1 ≤ 0`，落在可容许范围 `δ₁ > 0` 之外。在 `r ≤ 1` 上做
单样本 Chernoff，其阈值位于均值处或其下方，优化子在那里退化，界返回 `1`；这不是技术细节，
因为在 `α = 1000, β = 100α` 时 `r = 1` 处的真实概率是 `0.495857`，本质上就是二分之一，而目标
`e^{−α/8}` 是指数级小的。至于用精确 Beta 尾概率的精确双样本并集界，它在测过的每一格都通过，
但在最差点只留约 `2.2×` 的余量，而该区域的上确界是 `1/2`；整数参数的情形仍然需要把一个
`n` 次多项式在 `(α, β)` 上一致地界在 `e^{−cαr²}` 之下，那是一条大 `n` 渐近估计，不是一次改写。

因此**不存在任何一个范围，使论文的使用与论文的界同时成立**。这就是那处发现，也正是它让「反证」
成为成果物，而不是一段弯路。

### 3. Eq (40) 印出来的最后一步是假的

Eq (40) 印成三行链式不等式。以 600 dpi 对照 PDF 自身的字符流核验后，最后一行里
`1 − (16/η)e^{−η/8}` 外面**没有**括号：那个 `1` 是一项裸的加性常数，只有 `(16/η)e^{−η/8}`
带 `1/T`。但无论按哪种读法，这一步都是假的，而不只是无法复原。它的左边 `Σ_{l≤n} L·2e^{−ηl/8}`
与 `T` 无关，趋于 `L·2e^{−η/8}/(1 − e^{−η/8})`，右边则趋于 `1`；在论文自己的实验设定下
（`L = 20`，`η = 2`），左边是 `140.83`，右边在 `T = 10³` 时是 `1.0062`。这条印出来的不等式
在断言 `140.83 ≤ 1`，[DESIGN.md](DESIGN.md) §3.1 用一行算术证伪了它；`scripts/numeric_check.py`
并不覆盖这一条。

结论仍然成立，而理由值得写出来，因为正是它把这一处与 Lemma 5 那处分开：超出的是一个**常数
因子**，不是随 `T` 的增长。由 Corollary 1 有 `L/η ≥ C + D`，于是印出来的那一步大致断言
`16(C+D) ≤ 1`；尾部的常数倍超出在 `T` 上仍是 `O(1)`，再乘上 `K = Θ(LC(C+D))` 之后与主项之比
趋于 `0`。因此 `TSDPP/Tail.lean` 证明的是*正确*的界，指数常数作为参数 `c > 0` 出现；而
`theorem2_withTail` 把尾部保留为一个抽象的 `B`，只要求 `0 ≤ B`，不对两种表达式中的任一作出
承诺；上界 `B ≤ √log T` 只在 `B` 被吸收的地方进入，即 `theorem2_concrete` 与 `theorem2_rate`。

### 4. `L³` 这个指数并不是论文自己的算术所给出的

Theorem 2 与它的摘要彼此矛盾：§IV 写 `O(√(L³T log T))`，§I-C 与结论写 `O(√(T log T))`。只有当
`L` 被视为与 `T` 无关时二者才一致，而论文从未说明它指的是哪种。把论文自己的算术按符号 `L` 推
下去得到 `BR(T) ≤ Θ(L)·2√(8T(C+D) log T)`，即 `O(L√(T log T))`，这比它所声称的
`O(L^{3/2}√(T log T))` *更强*。所以 Theorem 2 未被证伪，而是被蕴含；但它印出来的指数并不是它
的推导所给出的，摘要里的那个也不是。成果物在三种读法之间保持中立：装配步骤以指数保持符号形式
的精确有限和陈述被机器校验，`theorem2_rate` 则把 `L` 留在明处，而不是替论文选一种约定。

### 5. `C` 与 `D` 不是与 `T` 无关的常数

论文在 Eq (38) 的前置因子 `(½C² + (2C² + 2CD + C)L)` 里用 `Y_i(t) ≤ C + D` 界住副本年龄，并在
那里把 `(C+D)` 当作确定性界使用。而状态界的唯一来源是 Lemma 6，那是一个*高概率*陈述，其中
`D = ⌈log ε / log(1−θ_i)⌉`。由此产生三个论文未处理的后果：`D` 依赖置信度 `ε`，从而依赖 `T`；
`Y ≤ C + D` 因此只在概率 `1 − ε` 下成立，不能被当作常数因子从期望里提出来，除非额外付一个
Eq (38) 并不携带的尾项；而 `C`——固定 arm 的最大重新选择间隔——本身就是策略所控制的东西，在
信念-DPP argmin 之下论文没有给出它的先验界。这个缺口是通过付 `O(ε·L·maxY)` 可以修补的，记录
在案而不是被悄悄补掉。

### 6. Eq (9) 的指标约定与 Eq (4) 不一致

Eq (4) 定义当 `π_i(t) = 1` 时 `Y_i(t) = X_i(t−1) + 1`；Eq (9) 用 `X_{A_t}(t)` 写同一个量，晚了
一个时隙。对确定性的 `X` 二者不可能同时对，差值恰好是事件触发那个时隙里的 `1`。形式化钉住
Eq (4) 的约定，因为 Eq (4) 是真正被定义出来的那个递推。Eq (35) 在该选择下不变，因为相减两侧
用的是同一个指标，所以 `penalty_diff` 两种约定下都不受影响；这个缺口被记账而不是被悄悄消解，
是因为它对任何在同一时隙上比较 `X_i(t)` 与 `Y_i(t)` 的陈述*会*有影响，而 Eq (36) 正是如此。

### 7. Lemma 3 与 Lemma 4 是作为假设携带的，不是作为公理

论文是从 [28] 引用二者，而非自行推导。`CLAUDE.md` 禁止为闭合目标引入公理，因此
`TSDPP/Theorem2.lean` 把分解式与每轮 Bellman 界作为显式前提 `hdecomp` 与 `hper` 承接，并证明
由它们推出的一切。接受 [28] 的读者免费得到 Eq (38)；不接受的读者能确切看到被假设的是哪一步。
被省掉的中间物是一个轨迹概率空间（带策略诱导的测度），以及其 `L¹` 上的 Bellman 算子，Mathlib
两者都没有。Lemma 4 本身*已经*以最一般的形式被证明（在任意测度空间上，见
`TSDPP/Simulation.lean`），但它没有被接上，因为它要被实例化所对着的那个轨迹律尚不存在。这是
整个开发中最大的未闭合输入。

## 成果物的边界

`FIDELITY.md` 审计一个无 `sorry` 的开发仍然可能证明错误定理的三种方式：太弱、空真、或发生
位移。它没有发现任何一种，同时它点明了边界。

**问题陈述没有被形式化。** 论文的 13 个编号环境都被逐条枚举并作出处置，但 `FIDELITY.md` §1.0.1
逐方程的清点把问题陈述与那两个定义标为 absent：Eq (5)–(7)、DPP 指标 Eq (10)、观测模型
Eq (11)、虚拟队列 Eq (12)、约束策略 Eq (13)、指标更新 Eq (14)、两个似然因子 Eq (20)–(21)、值
函数 Eq (17) 与贝叶斯遗憾 Eq (18)。`BR` 与 `J` 是作为满足假设的抽象实数进入 `theorem2_concrete`
的，而不是作为被定义的对象；`cards/R4.md` 记录 Eq (10)、(12)、(13) 有意置于范围之外。没有任何
东西被隐藏，但成果物形式化的是论文的*分析*，不是它的问题陈述；因此它有权作出的精确主张是：
*若*一个策略承认论文为其策略所推导的遗憾分解与集中事件，*则*它的遗憾服从论文的速率。它无权
主张论文自己那个受约束的策略达到了该速率。

**`O(·)` 这个符号本身没有被形式化。** `theorem2_rate` 是一条形如上式的机器校验 Lean 定理，其
常数显式且与 `T` 无关。要过渡到 `O(·)` 这个*符号*，需要在 `T` 上取一个滤子，并决定 `L` 是否随
它增长，这与第 4 条是同一个约定问题。那是一个建模决策，不是数学缺口，而成果物拒绝悄悄替它
作出决定。

**常数 `c₀ = 11/100` 未被推导。** 本来能为其提供依据的那条路线经过并集界的一个上确界，
而那个上确界主张已被撤回：所展示的上确界写错了，从它读出的有限 `α` 推论并不成立。活下来的是
那套参数化。`TSDPP/Tail.lean` 把尾部的指数常数陈述为参数 `c > 0`，而不是 `1/8` 或 `11/100`，
于是论文的常数与成果物的常数是同一条陈述的两个实例。`K₀ = 100/11` 经由集中假设 `hdelta` 与
`eq39_collapse` 进入，并被吸收进 `theorem2_rate` 的首项系数 `8`；该定理自身的被开方数是
`√(L³·(m·L)·logT/η)`。两种取法下速率都不变，因为该几何级数对每个 `c > 0` 都收敛。这也正是反证不依赖
那次撤回的原因：反例连论文自己的 `1/8` 也一并违反，按真实概率算是 `353×`。

**有一条路线被证明但尚未形式化。** `cards/L5-CONVEX.md` 载有一条论文层面的证明：`Beta(a,b)`
在凸序下被 `Γ(a, rate a+b)` 支配；这是在 Lemma 5 为真的那个范围上通往它的第二条独立路线。它
的任何一个节点都还没有进入 Lean。按本项目自己的标准，那张卡片并不闭合 Lemma 5；这里把它记为
欠账，而不是已完成。
