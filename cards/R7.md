# R7 — Theorem 1: Beta–Bernoulli conjugacy (paper Eq (21), (22))

**Status: CLOSED.**  `lean4/TSDPP/Conjugacy.lean`

## Statement

```
betaPDFReal_conj (α β : ℝ) (hα : 0 < α) (hβ : 0 < β) (A B : ℕ) {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
  betaPDFReal (α + A) (β + B) x
    = (beta α β / beta (α + A) (β + B)) * (x ^ A * (1 - x) ^ B) * betaPDFReal α β x

betaPDFReal_conj_all  -- same, with hx0/hx1 dropped (needed to make the lintegral form work)
lintegral_conj :
  ∫⁻ x, ENNReal.ofReal ((x ^ A * (1 - x) ^ B) * betaPDFReal α β x)
    = ENNReal.ofReal (beta (α + A) (β + B) / beta α β)
```

## Consumes

Nothing (Mathlib's `betaMeasure`, `betaPDFReal`, `lintegral_betaPDF_eq_one`).

## Consumed by

Nothing in the current DAG — R16's rate does not depend on the conjugacy statement, only on the
*existence* of the posterior family `Beta(α + A, β + B)` that Corollary 1 counts against.  R7 is
part of the artifact because Theorem 1 is a named result of the paper and the user asked for the
paper's results, not only its headline bound.

## Proof route

Unfold `betaPDFReal` to its `if 0 < x ∧ x < 1 then … else 0`, apply `ite_eq_left`, then move
between `Real.rpow` and monoid powers with `Real.rpow_add` and `← Real.rpow_natCast`, and close
with `field_simp` **alone** (trap P-17).  The `lintegral` form uses
`MeasureTheory.lintegral_congr` against a *pointwise* (not a.e.) lemma, then
`MeasureTheory.lintegral_const_mul'` — which avoids needing measurability of `betaPDF` — then
`lintegral_betaPDF_eq_one`.
