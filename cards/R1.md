# R1 — the event-AoI Markov chain (paper Eq (2), (3))

**Status: CLOSED.**  `lean4/TSDPP/Model.lean`

## Statement

`chainPMF θ x y = if y = 0 then θ else if y = x + 1 then 1 - θ else 0`

`chainPMF_sum_one : ∑ y ∈ range (x + 2), chainPMF θ x y = 1`   ← for **every** `θ : ℝ`
`chain_path_no_reset : ∏ x ∈ range d, chainPMF θ x (x + 1) = (1 - θ) ^ d`

## Consumes

Nothing.

## Consumed by

R12a (the tail bound multiplies the path probabilities).

## Proof route

The support is `{0, x+1}`; `Finset.sum_subset` restricts `range (x+2)` to it, then
`sum_insert`/`sum_singleton` and `ring`.  `chain_path_no_reset` is
`prod_congr` against `chainPMF_succ` + `prod_const` + `card_range`.

## Notes

* The two branches are disjoint because `x + 1 ≠ 0` — this is why no `if`-nesting side
  condition is needed.
* `chainPMF_sum_one` is unconditional in `θ`: the paper's Eq (2)(3) are a probability law for
  every `θ ∈ [0,1]`, including the degenerate endpoints.
