# R12a — Lemma 6: the state tail bound

**Status: CLOSED.**  `lean4/TSDPP/StateBound.lean` (+ `TSDPP/Model.lean`)

## Statement

```
tail_le_eps {θ ε : ℝ} (hθ0 : 0 < θ) (hθ1 : θ < 1) (hε0 : 0 < ε) :
  (1 - θ) ^ ⌈Real.log ε / Real.log (1 - θ)⌉₊ ≤ ε
```
combined with `chain_path_no_reset : ∏ x ∈ range d, chainPMF θ x (x+1) = (1−θ)^d`, which gives
`Pr(X_i(t) ≥ d) = (1−θ)^d`.

## Consumes

R1 (`chain_path_no_reset`).

## Consumed by

R10 (as the hypothesis `δ ≤ C`), R13 (as `α^l_i ≥ ηl` via Corollary 1).

## Proof route

`Nat.le_ceil` gives `log ε / log(1−θ) ≤ ⌈·⌉`; multiplying by the **negative** `log(1−θ)` reverses
the inequality to `⌈·⌉·log(1−θ) ≤ log ε`.  Then `(1−θ)^d = exp(d·log(1−θ)) ≤ exp(log ε) = ε`
through `Real.exp_le_exp`.

## Notes — a deliberate strengthening

The paper states Lemma 6 "for any `ε > 0`" and then reasons with `ε ∈ (0,1)`.  The hypothesis
`ε < 1` was in the first draft, the linter flagged it unused, and it was **dropped** — the proof
never needs it and for `ε ≥ 1` the bound is trivial.  The theorem is therefore strictly stronger
than the paper's statement.
