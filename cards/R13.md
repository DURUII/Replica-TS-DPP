# R13 — Eq (40): the geometric tail of the concentration-failure terms

**Status: CLOSED.**  `lean4/TSDPP/Tail.lean`

## Statement

```
geom_exp_sum_le (η c : ℝ) (hη : 0 < η) (hc : 0 < c) (N : ℕ) :
  ∑ l ∈ range N, Real.exp (-(c * η * ((l : ℝ) + 1)))
    ≤ Real.exp (-(c * η)) / (1 - Real.exp (-(c * η)))

tail_sum_le (N L : ℕ) {η c : ℝ} (hη : 0 < η) (hc : 0 < c) :
  ∑ l ∈ range N, ∑ _t ∈ range L, 2 * Real.exp (-(c * η * ((l : ℝ) + 1)))
    ≤ (L : ℝ) * (2 * Real.exp (-(c * η)) / (1 - Real.exp (-(c * η))))
```

The tail exponent is a **parameter** `c > 0`, not a fixed `1/8`: the paper's `8` is the instance
`c = 1/8`, and the artifact substitutes `c = 11/100` (see the integration caveat below).

## Consumes

**`L5` = Lemma 5 of the paper, quoted from [45]** — *as a hypothesis, not an axiom*.  The card
proves the arithmetic *downstream* of the concentration bound: it takes `r^l_i = 1` and
`α^l_i ≥ ηl` (both supplied by Corollary 1) as the inputs that turn `e^{−α^l(r^l)²/8}` into
`e^{−cηl}` — the paper's `e^{−ηl/8}` is the instance `c = 1/8`, the artifact's is `c = 11/100`.

## Consumed by

R16.

## Proof route

`exp(−cη(l+1)) = r^(l+1)` with `r = exp(−cη)` via `Real.exp_nat_mul` (note: it places the
*natural number on the left*, `exp (↑n * x) = exp x ^ n` — trap T4), then `sum_mul` + `pow_succ`,
then the finite partial-sum bound `Σ_{l<N} r^l ≤ 1/(1−r)` from `geom_sum_mul_neg` plus `r^N ≥ 0`,
moved through `le_div_iff₀`.  Deliberately avoids `tsum_geometric_of_norm_lt_one`, so no
summability side conditions arise.  `hη : 0 < η` and `hc : 0 < c` are genuinely necessary
(`η = 0` or `c = 0` makes the RHS `1/0`).

## Notes — **GAP-6: the bound is stated for arbitrary `N` on purpose**

The paper truncates the episode sum at `n = ⌈8 log T/η⌉` before applying this bound.  Truncation
only *shrinks* the sum, so the bound is stated for arbitrary `N` and remains valid whatever the
truncation index is.  That is also why the three steps of Eq (40) that the paper does not justify
are out of scope here and are recorded in `../DESIGN.md` §7 GAP-6:
1. the truncation index and the resulting `2m/T` slack term;
2. the `≤ 2e^{−ηl/8}` step, which consumes Corollary 1 (GAP-3);
3. the printed constant `(1 − (16/η)e^{−η/8})·(1/T)`, which is `O(1/T)` where the derivation
   supports `O(L/η)`.  The bound proved here is asymptotically **sharp** (numerically:
   `η = 0.5, N = 1000`: LHS `15.505207994280665` vs RHS `15.505207994280672`).

> **Why `K = 1/c₀` and not the paper's `K = 8`, stated precisely.** The paper's `8` is coupled
> across three places, and it is easy to conflate two of them (this file's first draft did, and
> `DESIGN.md` P-19 is corrected accordingly):
> * Eq (33) sets the radius `r = √(8 log T/α)` so that `αr²/8 = log T`, making the failure
>   probability `2e^{−log T} = 2/T`;
> * Eq (40) uses `2e^{−α^l/8}`, which comes from `r^l ≥ 1 ⟹ (r^l)² ≥ 1` — so the *tail* exponent
>   carries `r² = 1`, **not** the `8` of the radius;
> * the threshold `n = ⌈8 log T/η⌉` and the `2m/T` term are the same fact read twice.
> Consequently the tail's geometric ratio is `e^{−c₀η}` for *any* `K`; `K` only controls the `2m/T`
> term, and `c₀K = 1` is exactly what preserves it.
>
> With `K = 8` the tail term becomes `2m/T^{0.88} = O(T^{0.12}/L)`. That does **not** destroy the
> rate — it is dominated by the main term, since `T^{0.12}/(L^{1.5}T^{0.5}√log T) → 0` — but it is
> no longer `O(1/L)`, so the final bound would hold only with a `T`-dependent constant or a
> `T ≥ T₀` side condition. `K = 100/11` gives `c₀K = 1` *exactly* (that is all `100/11` is: the
> reciprocal of `11/100`), so the paper's clean `2m/T` survives and the constant stays `T`-free.
>
> The bound proved *here* was true as stated at `1/8`, but that was not the bound the chain
> consumes; after the re-statement above it **is** the bound the chain consumes.  `DESIGN.md` §6
