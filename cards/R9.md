# R9 — Lemma 2: two Lipschitz bounds on the belief law (paper Eq (23), (24), (25), (26))

**Status: CLOSED.**  `lean4/TSDPP/Lipschitz.lean` (+ `lean4/TSDPP/Ineq.lean`)

## Statement

```
l1_lipschitz         : ∑ x ∈ range (λ+δ+1), |P^θ_x − P^θ'_x|      ≤ 2δ·|θ − θ'|
firstMoment_lipschitz: ∑ x ∈ range (λ+δ+1), x·|P^θ_x − P^θ'_x|    ≤ (δ(δ−1)/2 + δ(λ+δ))·|θ − θ'|
```
both for `θ, θ' ∈ [0,1]`.

Analytic core (Eq (25)):
```
armTerm_lipschitz : |b(1−b)^x − a(1−a)^x| ≤ |b − a|          (MVT + arm_deriv_abs_le_one)
arm_deriv_abs_le_one : |(x+1)u^x − x·u^{x−1}| ≤ 1            for u ∈ [0,1]
atomTerm_lipschitz : |(1−θ)^δ − (1−θ')^δ| ≤ δ·|θ − θ'|        (Eq (26), via abs_pow_sub_pow_le)
```

## Consumes

R5 (`pmf` and its support lemmas).

## Consumed by

R10 (`Regret.beliefMean_diff_le` is literally `firstMoment_lipschitz` + `abs_sum_le_sum_abs`, and
`Regret.stateTerm_le` uses `l1_lipschitz`).

## Proof route

`Convex.norm_image_sub_le_of_norm_deriv_le` on `Icc 0 1` for the `armTerm` half, with the
derivative bound coming from the two Bernoulli corollaries of `TSDPP/Ineq.lean`:
`pow_add_weighted_le_one'` (positive half) and `succ_mul_pow_sub_le_one'` (negative half).  The
`atomTerm` half avoids a second MVT argument by using `abs_pow_sub_pow_le` and observing that
`max |u| |v| ≤ 1` on `[0,1]`.  The sums then split into `δ` copies of `armTerm` plus one
`atomTerm`.

## Notes — three traps, all recorded

* **P-3** the bound must be uniform on the **closed** `[0,1]`; the numeric falsifier gave
  `sup|f'| = 1.0` exactly, attained at `θ = 0`.
* **P-4** the constants `2δ` (Eq 23) and `δ(δ−1)/2 + δ(λ+δ)` (Eq 24) are **tight** — the numeric
  falsifier returns `1.0000000000000113` and `1.0000000000000226` respectively.  Neither may be
  "improved" anywhere downstream.
* **P-10** the paper prints `f'(ξ) = (1−ξ)^{x−1}(1−(x+1)ξ)`, which is wrong at `x = 0` under Lean's
  truncated `ℕ`-subtraction.  The card uses the un-truncated form.
