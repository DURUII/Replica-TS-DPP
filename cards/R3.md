# R3 — the per-slot penalty identity (paper Eq (9))

**Status: CLOSED.**  `lean4/TSDPP/Model.lean`

## Statement

For `γ : Fin N → ℝ` with `∑ i, γ i = 1`, an arm `a`, and pre-slot states `X`, `Y`:

```
∑ i, γ i * (if i = a then (X i : ℝ) + 1 else (Y i : ℝ) + 1)
  = (∑ i, γ i * (Y i : ℝ)) + 1 + γ a * ((X a : ℝ) - (Y a : ℝ))
```

## Consumes

Nothing.

## Consumed by

R15.

## Proof route

Per-term case analysis (`subst hia; rw [ite_eq_left rfl]; simp only [ite_true]; ring`), then
`sum_add_distrib`, `simp_rw [mul_add, mul_one]`, and `sum_ite_eq'` for the singleton pick.

slot.  This card pins **Eq (4)'s** convention: `X` is the *pre-slot* event AoI `X_i(t−1)`.
