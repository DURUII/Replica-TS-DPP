## Statement

The core arithmetic lemma, at the artifact's radius constant `K₀ = 100/11` (the paper's `8`):

```
lemma rate_core {L m : ℕ} {η logT B : ℝ}
    (hη : 0 < η) (hlogT : 1 ≤ logT) (hL : 1 ≤ L)
    (hBle : B ≤ Real.sqrt logT) (hηT : η ≤ (L : ℝ) ^ 4 * (m : ℝ)) :
    2 * (L : ℝ) * Real.sqrt ((100 / 11) * (m : ℝ) * logT / η) + B
      ≤ 8 * Real.sqrt ((L : ℝ) ^ 3 * ((m : ℝ) * (L : ℝ)) * logT / η)
```
Its constant-free ingredient is `two_mul_sqrt_ratio_le` (the renamed `two_mul_sqrt_eight_le`):
```
lemma two_mul_sqrt_ratio_le {x : ℝ} (hx : 0 ≤ x) :
    2 * Real.sqrt ((100 / 11) * x) ≤ 7 * Real.sqrt x
```

The honest, hypothesis-explicit form of the paper's Theorem 2:

```
regret_bound {m L : ℕ} {C D : ℕ} {η : ℝ} ... :
  |BayesRegret m L| ≤ regretCoeff C D L * (2 * Real.sqrt ((100 / 11) * m * Real.log T / η))
                      + (tail term)
```
with `T = m·L`, `K = C²/2 + (2C²+2CD+C)·L` (from R11), and the two cited lemmas carried as
**named hypotheses**:

* **`L34` (Lemma 3, Lemma 4 — [28])**: the Bellman-operator regret decomposition bounding the
  episodic regret of a DPP policy by `Σ_t (per-round perturbation)`.
* **`L5` (Lemma 5 — [45])**: the concentration bound `Pr(|θ̂ − θ| ≥ r) ≤ 2e^{−α r²/8}` for the
  Beta posterior (the artifact carries `c₀ = 11/100` in place of the paper's `1/8`).

## Proof route

`regret_le` (R11) reduces everything to `K · Σ_l Σ_t delta l t`.  Substituting `delta l t = √((100/11) log T/ηl)`-shaped terms and applying `sum_inv_sqrt_weighted` (R14) gives
`K · L · 2√((100/11) m log T / η)`; the episodes beyond the truncation index are bounded by
`tail_sum_le` (R13).

## The exponent check

With `T = mL` and `K = Θ(L)`,

```
K · L · 2√((100/11) m log T / η)  =  Θ(L) · L · √(L·T log T / L)
                           =  Θ(L² · √(T log T / L))
                           =  Θ(L · √(L T log T))
                           =  Θ(√(L³ T log T)),
```
which is exactly the paper's Theorem 2 rate `O(√(L³ T log T))`.  The `L` in the numerator and the
`L` inside the square root cancel against the `L = T/m` from converting `m` to `T`.

## GAP-6 will not change this

The paper's printed tail constant in Eq (40) is off (see R13 and `../DESIGN.md` §7 GAP-6), but
the tail is `O(L/η)` against a leading term of `Θ(L·√(LT log T))`, so it is **absorbed** for
`T ≥ 2` and the exponent is unaffected.  Recorded explicitly rather than silently.

## Notes — two corrections made after the first draft

* **Unused hypotheses dropped (trap P-14, third occurrence).**  `rate_core` carried `0 ≤ B` and
  `1 ≤ m`; the linter flagged both unused, and they were removed rather than silenced, making the
  statement strictly stronger.  `B < 0` is fine because the right side is `≥ 0`; `m ≥ 1` is never
  needed since the proof only uses `m ≥ 0` via `Nat.cast_nonneg`.  The `0 ≤ B` hypothesis is
  re-supplied by the *caller* (`Theorem2.theorem2_concrete`), where it is genuinely needed.
* **The constant `8` is near-tight.**  Numerically, `max (2L√(K₀Z)+B)/√(L⁴Z) = 2√(100/11) + 1 =
  7.030227`, attained at `L = m = logT = η = 1`, `B = √logT`, where `K₀ = 100/11` and
  `Z = m·logT/η`.  Any constant below that fails on that witness, so `8` is not slack (trap P-19);
  in particular `6` is now **false** (`2√(100/11) = 6.030227 > 6`).  The paper's constant, at its
  `√8`, gave `2√8 + 1 = 6.656854`.
* **The internal split is `8 = 7 + 1`.**  It was `7 = 6 + 1` at the paper's `√8`.  Now
  `2L√(K₀Z) ≤ 7√(L⁴Z)` — via `1 ≤ L` and `two_mul_sqrt_ratio_le` at `x = L⁴Z`, whose side
  condition is `K₀ = 100/11 ≤ 49/4` (**not** `≤ 49`, which would need `9 ≥ 100/11` and is false) —
  plus `B ≤ √(log T) ≤ √(L⁴Z)`.
