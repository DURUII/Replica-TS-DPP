# R10 — Eq (36) and Eq (37): the per-round parameter-perturbation budget

**Status: CLOSED.**  `lean4/TSDPP/Regret.lean`

## Statement

**Eq (36)** — the penalty difference, from Eq (35) + Eq (24):
```
perRoundPenaltyDiff_le {N} {γ : Fin N → ℝ} (hγ0 : ∀ i, 0 ≤ γ i) (hγ1 : ∑ i, γ i = 1) (a : Fin N)
    {C L λ δ : ℕ} (hδ : δ ≤ C) (hY : λ + δ ≤ L) (hθ : θ ∈ Icc 0 1) (hθ' : θ' ∈ Icc 0 1) :
  |γ a * (∑ x, x·P^θ_x − ∑ x, x·P^θ'_x)| ≤ (C²/2 + C·L)·|θ − θ'|
```
**Eq (37)** — the value-function term, from Eq (23):
```
stateTerm_le {λ δ C D L : ℕ} {J : ℕ → ℝ} (hδ : δ ≤ C) (hJ : ∀ x, |J x| ≤ (C+D)·L) (hθ) (hθ') :
  |∑ x ∈ range (λ+δ+1), (P^θ_x − P^θ'_x)·J x| ≤ 2·C·(C+D)·L·|θ − θ'|
```

## Proof route

* Eq (36): `beliefMean_diff_le` turns the difference of means into `Σ x·|P − P'|` via
  `abs_sum_le_sum_abs`, then `firstMoment_lipschitz` applies.  `meanCoeff_le` upgrades the Lemma 2
  constant `δ(δ−1)/2 + δ(λ+δ)` to `C²/2 + C·L` using `δ ≤ C` and `λ+δ ≤ L`, and `weight_le_one`
  disposes of `γ_a`.
* Eq (37): `abs_mul` per term, `sum_le_sum`, factor `(C+D)L` out of the sum, then
  `l1_lipschitz` and `δ ≤ C`.

## Notes — the `LC` vs `C(C+D)` question

The paper writes `LC` in Eq (36), and Eq (38) *only* closes with `LC`.  The route through Lemma 6's
`λ + δ ≤ C + D` gives `C(C+D)` instead and leaves `2C²L` unmatched in Eq (38).  `LC` is valid for
a different reason: inside an episode of length `L`, the copy-AoI satisfies `λ + δ ≤ L`
trivially.  Both are true; only one reproduces the printed constant.  Numeric check of the
expansion is in `../DESIGN.md` §8; see also route J-9 in §5 and trap P-13.

## Open sub-nodes

None *in the Lean sense*.  The hypotheses `δ ≤ C` and `λ + δ ≤ L` are precisely GAP-3 — the paper
asserts them and proves neither.
