# R6 — the belief-state mean (paper Eq (16))

**Status: CLOSED.**  `lean4/TSDPP/Belief.lean`

## Statement

For `θ ≠ 0`:
```
∑ x ∈ range (lam + δ + 1), (x : ℝ) * pmf θ lam δ x
  = (1 - θ) / θ + (1 - θ) ^ δ * ((lam : ℝ) - (1 - θ) / θ)
```

## Consumes

R5.

## Consumed by

R9 (`firstMoment_lipschitz` composes it with the Lipschitz bound), R10.

## Proof route

`Belief.weighted_geom_sum`, proved by **induction on `δ`** rather than by routing through
`geom_sum_eq`.  The latter would force a `1 − θ ≠ 1` case split that the induction does not need
(trap P-2).

## Notes — the `θ ≠ 0` hypothesis

Eq (16) divides by `θ`.  The formalization claims the identity only for `θ ≠ 0`; at `θ = 0` the
chain is absorbed at `∞` with weight `0` and the printed formula is meaningless.  This is a
weakening *against the paper*, recorded rather than hidden.
