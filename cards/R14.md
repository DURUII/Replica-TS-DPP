# R14 — Eq (39): the finite-sum assembly

**Status: CLOSED.**  `lean4/TSDPP/Assembly.lean`

## Statement

```
sum_range_inv_sqrt_le (m : ℕ) : ∑ l ∈ range m, 1 / √(l + 1) ≤ 2 * √m

sum_inv_sqrt_weighted (m : ℕ) {C η : ℝ} (hC : 0 ≤ C) (hη : 0 < η) (ηl : ℕ → ℝ)
    (hηl : ∀ l : ℕ, η * (l + 1) ≤ ηl l) :
  ∑ l ∈ range m, C / √(ηl l) ≤ (C / √η) * (2 * √m)
```

## Consumes

Nothing (pure real arithmetic).

## Consumed by

R16.

## Proof route

The telescoping estimate `1/√(l+1) ≤ 2(√(l+1) − √l)`, which follows from the conjugate identity
`√(l+1) − √l = 1/(√(l+1) + √l)` and `√l ≤ √(l+1)`; the right-hand side sums to exactly `2√m`
(`sum_range_sqrt_sub`, by induction, avoiding a `sum_range_sub` API lookup).  The weighted form
pulls `√η` out with `Real.sqrt_mul` and applies `one_div_le_one_div_of_le`.

## Notes

This is where the paper's `2√m` comes from, and it is **sharp**: the numeric falsifier gives
`max_m (Σ_{l<m} 1/√(l+1))/(2√m) = 0.988516` (row "Eq(39)" of `scripts/numeric_check.py`).
Corollary 1's `α^l_i ≥ ηl` is the `hηl` hypothesis.
