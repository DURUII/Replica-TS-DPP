theorem2_concrete {m L : ℕ} {η logT K B : ℝ}
    (hη : 0 < η) (hlogT : 1 ≤ logT) (hL : 1 ≤ L) (hK : 0 ≤ K)
    (hB0 : 0 ≤ B) (hBle : B ≤ Real.sqrt logT)

## Proof route

Four steps, each a previously-closed card:

1. `Regret.regret_le` (R11): `|BR| ≤ K · Σ_l Σ_t delta l t`.
2. `eq39_collapse` (R17's own lemma, from R14): the divergence collapses to `L · 2√((100/11)m log T/η)`.
3. `le_add_of_nonneg_right hB0` re-admits the tail `B`.
4. `Rate.rate_core` (R16): `2L√(K₀Z) + B ≤ 8√(L⁴Z)` with `K₀ = 100/11`, `Z = m·log T/η`, and
   `K ≥ 0` carries it through.

Step 2 is the only new mathematics here; it is `sum_inv_sqrt_weighted` with `C = √((100/11) log T)`, plus
the observation that the inner sum over the `L` rounds contributes a factor `L`.

## Why this is Theorem 2

`theorem2_rate` is the paper's rate with every constant explicit: substituting
`K = regretCoeff C D L` and applying `regretCoeff_le_mul` (`K ≤ (½C² + 2C² + 2CD + C)·L`) turns
`theorem2_concrete` into `|BR| ≤ c·L·√(L³T log T/η)` with `c = 8·(½C² + 2C² + 2CD + C)`
**independent of the horizon**.

So the entire numerical content of Theorem 2 is machine-checked.  What remains is passing from
that inequality to the `O(·)` *symbol*, which requires a filter on `T` and an answer to GAP-4
(does `L` grow with `T`?) — neither of which the paper supplies.  That is a modelling decision,
not a gap in the mathematics; `FIDELITY.md` §4 carries the discussion.

## Notes

* **The radius constant is the artifact's `K₀ = 100/11`, not the paper's `8`.**  `L5` is proved at
  `c₀ = 11/100`, and `K₀ = 1/c₀` is what preserves the paper's `2m/T` failure bound; the same `K₀`
  appears in `hdelta`'s radical and in `eq39_collapse`.  The final constant rose `7 → 8` accordingly
  and is now near-tight at `2√(100/11) + 1 = 7.030227` (see R16).  The tail exponent is a *parameter*
  `c > 0` (paper `1/8`, artifact `11/100`) throughout `Tail.lean`.  The rate `O(√(L³T log T))` is
  unchanged.
* **The tail is not hidden.**  `B` is an explicit parameter with `0 ≤ B` and `B ≤ √log T` as
  named hypotheses, not folded into a constant.  GAP-6 says the paper's Eq (40) constant is not
  reconstructible; making `B` explicit is how that gap stays visible at the headline.
* **`O(·)` is deliberately absent.**  Formalizing `= O(·)` would require committing to a filter on
  `T` the paper never pins down (GAP-4).  The concrete bound is strictly stronger.
* **Numerically falsified.**  Both `eq39_collapse` (max `LHS/RHS = 0.889`) and `theorem2_concrete`
  (0 violations over a grid at the `hηT` / `hBle` boundaries) were checked before the proofs were
  trusted — the same discipline applied to R9's tight constants.
